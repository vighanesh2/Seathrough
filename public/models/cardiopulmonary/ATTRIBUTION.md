# Cardiopulmonary model attribution

The three reference meshes in this directory are licensed under
[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
They are used as educational reference surfaces and are transformed at runtime
by recentering, uniform scaling, transparency, and application materials.

- Kristen Browne; Heidi Schlehlein. 2022. *3D Reference Organ for Heart,
  Male v1.2.* [doi:10.48539/HBM373.VSTV.568](https://doi.org/10.48539/HBM373.VSTV.568).
- Kristen Browne; Heidi Schlehlein. 2023. *3D Reference Organ for Lung,
  Male v1.3.* [doi:10.48539/HBM737.FFBT.876](https://doi.org/10.48539/HBM737.FFBT.876).
- Kristen Browne; Heidi Schlehlein. 2023. *3D Reference Organ for Main
  Bronchus, Male v1.0.* [doi:10.48539/HBM795.LVRX.842](https://doi.org/10.48539/HBM795.LVRX.842).

The models were created from the National Library of Medicine Visible Human
Male dataset and distributed through the NIH 3D / Human Reference Atlas
collection. See `asset-manifest.json` for source entries, file identifiers,
checksums, and transformation notes.
