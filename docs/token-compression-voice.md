# Token compression — Step 5: Voice constraint

Spoken length + readable sentences. Paste below.
1. One-canvas spoken length

How long may this lesson talk before it is too much?
Pick a hard cap you will actually enforce, for example:

45–75 seconds of speech, or
~80–120 spoken words (about what is in a good ship-short)

If Pipe B’s pane needs two minutes, it is two canvases or it failed the trim. Not “read faster.”
2. Speakable sentences

Voice may only read full teaching sentences.
Fail:

keyword soup (“class object blueprint instance classroom”)
telegram fragments
a list of five nouns with no verb

Pass: the ship-short you already wrote for Java / heart / gravity.
3. Same text, two surfaces

Right pane and voice are the same words.

Do not generate a “narration style” paragraph and a short pane. That is how Claudish comes back through the speaker.
4. What the voice must cover

The ear has to hear the five unit fields, not a vibe:

name
one-sentence core concept
scope in a clause if needed (“not inheritance”)
mapping (“classroom is the class”)
next step

If the mapping only exists as a picture caption the voice never says, the gate fails for a listener who is not looking.
